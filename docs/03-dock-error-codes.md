# Dock error codes

Code E11: the battery of the dock is low. The dock still accepts returns, but it cannot release bikes. Use another dock of the same station.

Code E17: the lock of the dock is jammed. Do not pull the bike harder. Report the dock in the app with one tap, and the ride is not charged.

Code E23: the payment was declined. Check the card in your account, or buy a day pass at the kiosk.

Code E42: the bike was reported as damaged by the previous rider and stays locked until a mechanic checks it. Choose another bike.
